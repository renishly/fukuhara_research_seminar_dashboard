{# The two values an agent's connector needs. site_url is this dashboard's address as your browser sees it. #}

Give your agent's connector these two values (see Implement connector in the sidebar):

DASHBOARD_URL={{ site_url }} DASHBOARD_API_KEY={{ api_key or "the-key-you-entered" }} {% if "://127.0.0.1" in site_url or "://localhost" in site_url %}

This is a local address: it only works for agents on this same computer. Use the deployed address (e.g. https://your-service.onrender.com) for agents running elsewhere.

{% endif %}
